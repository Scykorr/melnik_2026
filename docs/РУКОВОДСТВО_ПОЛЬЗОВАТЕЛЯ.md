# Руководство: как развернуть и запустить ИАМ «Регион»

Полное название системы: «Разработка автоматизированной системы мониторинга протестной активности населения для подготовки ИАМ «Регион»».

Приложение смотрит открытые публикации и собирает из них события, темы и территориальную сводку. Оно не составляет списки людей и не оценивает чьи-либо взгляды. Данные команды `seed_demo` вымышленные.

## Что нужно заранее

- Windows 10/11 или Linux.
- Python 3.11 или новее. В этом проекте проверены 3.13 и 3.14 с Django 5.2.18.
- Для полного стенда: Docker с PostgreSQL 17 и Redis 7. Без Docker приложение работает на SQLite.

## Быстрый запуск на Windows

Дважды щёлкните `start.bat` в корне проекта. Тот же запуск из PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run.ps1
```

Скрипт создаёт `.env`, при первом запуске ставит зависимости, применяет миграции, загружает синтетические данные и открывает сервер на http://127.0.0.1:8000/ . Окно браузера открывается само. Остановка: Ctrl+C в окне сервера.

## Быстрый запуск на Linux

```sh
bash scripts/run.sh
```

## Запуск через Docker

```sh
cp .env.example .env
docker compose up -d --build
docker compose exec web python manage.py seed_demo
```

Сайт: http://127.0.0.1:8000/ . Остановка: `docker compose down`.

Проверка готовности:

```sh
python manage.py readycheck
```

Адреса `/health/live` и `/health/ready` отвечают, жив ли процесс и доступны ли база с кэшем.

## Как войти

| Кто | Логин | Пароль |
| --- | --- | --- |
| Администратор | admin | admin |
| Оператор | operator | Operator-IAM-2026! |
| Аналитик | analyst | Analyst-IAM-2026! |
| Согласующий | approver | Approver-IAM-2026! |
| Аудитор | auditor | Auditor-IAM-2026! |

Пароли годятся только для учебного стенда. Django admin открывается по адресу http://127.0.0.1:8000/admin/ с логином `admin` и паролем `admin`. Это та же учётная запись, что и в основном интерфейсе.

Интерфейс рассчитан на работу без интернета. Стили, значок, шрифт и графики сводки берутся из каталога `static/`. Django admin использует свои файлы из установленного Django и тоже отдаёт их локально. Сеть нужна только если оператор сам запускает загрузку внешней ссылки или RSS.

## Как работать в интерфейсе

1. Аналитик открывает «Сводку», выбирает территорию и период. Карточка индекса показывает версию формулы, число событий, число источников, долю ручной проверки и предупреждение, что индекс описывает информационный поток.
2. В «Очереди проверки» можно отфильтровать события и назначить аналитика. Подтвердить пачку карточек одной кнопкой нельзя.
3. В карточке события видны публикации, объяснение группировки и история решений. Подтверждение и отклонение требуют комментарий.
4. «Конструктор ИАМ» собирает черновик. Серый блок — автотекст, зелёный — текст аналитика. Согласующий утверждает версию. После этого её уже нельзя поправить.
5. Экспорт DOCX и PDF доступен из карточки отчёта.
6. Оператор ведёт источники и может безопасно повторить загрузку. Ошибки показываются короткой фразой, без технических трасс.
7. Аудитор читает журнал. Менять данные он не может.
8. Раздел «Испытания» принимает реальные замеры времени. Пока пар AS-IS и TO-BE нет, экономия времени показана как «не измерено».

## Полезные команды

```powershell
.\.venv\Scripts\python.exe manage.py seed_demo --force
.\.venv\Scripts\python.exe manage.py evaluate_dedup --dataset ИМЯ --method tfidf --split test
.\.venv\Scripts\python.exe manage.py estimate_effect --t0 8 --t1 5 --n 12 --c 500 --c-op 100000
.\.venv\Scripts\python.exe manage.py purge_derived --before 2020-01-01 --reason "истёк срок хранения"
```

Команда оценки дедупликации откажется считать метрики, если эталонный файл не загружен. Экономическая команда печатает прогноз, а не фактический результат.

## Резервная копия

Для PostgreSQL:

```powershell
$env:DATABASE_URL = "postgres://iam:iam@localhost:5432/iam"
powershell -ExecutionPolicy Bypass -File scripts/backup.ps1
pg_restore --clean --if-exists --dbname $env:DATABASE_URL backup\iam-ДАТА.dump
```

```sh
DATABASE_URL=postgres://iam:iam@localhost:5432/iam sh scripts/backup.sh
pg_restore --clean --if-exists --dbname "$DATABASE_URL" backup/iam-ДАТА.dump
```

SQLite достаточно скопировать файл `db.sqlite3` при остановленном сервере.

## Если сервер не открывается

- Порт 8000 занят: закройте прежний `runserver` или укажите другой порт `manage.py runserver 127.0.0.1:8001`.
- Повторный `seed_demo` ничего не дублирует. Полная пересборка: `seed_demo --force`.
- На Windows worker Celery, если он нужен отдельно, запускайте так: `celery -A config worker --loglevel=info --pool=solo`.

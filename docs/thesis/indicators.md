# Показатели

| Показатель | Роль | Факт | Цель, не результат |
| --- | --- | --- | --- |
| T0 | трудозатраты ручного выпуска, ч | не измерено | снять по протоколу |
| T1 | трудозатраты выпуска с системой, ч | не измерено | снять по протоколу |
| K_T | (T0−T1)/T0×100% | не измерено | считается только по сопоставимым парам |
| F1 релевантности | качество отбора публикаций | не измерено | не ниже 0.85 |
| Precision объединения | качество дедупликации | не измерено | не ниже 0.95 |
| Recall событий | полнота обнаружения | не измерено | не ниже 0.90 |
| P95 API | скорость | не измерено | не выше 1.5 с |
| ИПА | содержательный индекс потока, не KPI разработки | считается на синтетике | не использовать как доказательство эффекта |

Качество и подтверждаемость блокируют интерпретацию ускорения. Синтетическая витрина не заменяет эти измерения.

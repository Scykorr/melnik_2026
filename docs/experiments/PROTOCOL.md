# Протокол сравнения ручной и системной подготовки

Нужно не меньше 10 сопоставимых заданий в режиме `as_is` и 10 в режиме `to_be`. Порядок режимов чередуется. Шаблон ИАМ, набор источников и критерий правильности одинаковые.

Для каждой сессии записываются: код пакета, анонимный код аналитика, число документов и событий, минуты поиска, очистки, дедупликации, проверки, расчёта, написания и правок, отдельно минуты ожидания фона, число фактических ошибок, полнота, ложные включения, ошибки дат и территорий, отсутствие ссылок.

Незавершённая сессия не считается выпуском. Если нет ссылок или полнота низкая, пара несопоставима и K_T по ней не считается.

Реальные числа вносятся только после эксперимента. Этот файл не содержит измерений.
